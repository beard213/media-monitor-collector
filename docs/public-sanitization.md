# Public Sanitization Notes

This repository is prepared for public portfolio use.

Excluded from version control:

- `.env` and environment-specific configuration
- browser profiles, cookies, session files, and private login state
- downloaded videos, images, thumbnails, temporary files, and exports
- runtime logs, collection job records, and pipeline run outputs
- production server IPs, internal filesystem paths, and private task documents

Keep real collection data and credentials outside the repository.
